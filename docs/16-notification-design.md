# Notification Design

## 目的
情報を大量に送るのではなく、重要な資金調達機会を適切なタイミングで届ける。

## Priority
- Critical: 締切が近く、必須条件を満たし、根拠が強い
- High: 適合度が高く、準備期間がある
- Normal: 検討価値はあるが緊急性が低い
- Digest: 関連情報を定期的にまとめる

## MVP Channels
- Web通知
- Email

## 配信制御
- 同一助成金の重複通知を抑制
- 重要条件が変更された場合のみ再通知
- 団体ごとの頻度設定
- 既読・保存・却下を記録
- 締切リマインドは申請案件を基準にする

## 通知本文
1. 助成金名
2. なぜこの団体に関連するか
3. 締切
4. 助成額等の主要条件
5. 未確認事項
6. 公式情報源

## Fail-safe
送信失敗はキューへ戻す。成功記録後に再送を抑止し、同一イベントの二重送信を防ぐ。
