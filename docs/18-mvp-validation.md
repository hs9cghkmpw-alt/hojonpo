# MVP Validation Plan

## 目的
大規模開発前に、NPOが継続して使う価値があるかを検証する。

## MVP Scope
1. NPOプロフィール登録
2. 少数の公式情報源の監視
3. 助成金DB
4. 条件フィルタ
5. AIマッチング
6. 公式出典付き通知
7. 保存・却下
8. 締切管理

申請書自動生成はPhase 2。最初から全部作らない。

## Pilot
5〜10団体程度で検証する。実在団体の公開情報と本人提供情報を利用する。

## 仮説
- NPOは全件一覧より自団体に関係する候補を評価する
- 適合理由と根拠が応募判断に役立つ
- 申請準備支援へ進む団体ほど継続価値が高い
- 自動収集・マッチングにより運営者の作業時間が増えにくい

## 実験
- 即時通知 vs 週次Digest
- 理由付きカード vs 一覧
- マッチング根拠表示あり/なし
- 無料利用 vs 有料パイロット

## 計測
登録率、週次アクティブ率、既読率、保存率、応募開始率、誤マッチ率、運営作業時間、支払い意思を記録する。

## 撤退/方向転換条件
通知が行動につながらない、情報源維持コストが高すぎる、無料手段との差を説明できない場合は、機能追加より価値仮説を再検証する。
