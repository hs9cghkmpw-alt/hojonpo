# ビジネスモデル仮説

## 売るもの

「助成金情報」ではなく「NPOの資金調達担当機能」を月額で提供する。

## 無料検索との差

検索
→ 自動監視
→ 団体別マッチング
→ 通知
→ 申請準備
→ 過去資料再利用
→ 締切管理
→ 結果蓄積

までを一つの継続業務として提供する。

## 継続課金の根拠

新しい公募は継続的に発生するため、登録している限り継続的に価値が発生する構造を目指す。

## 価格

価格は未確定。

初期仮説:
- Free: 検索/閲覧
- Basic: 自動マッチング・通知
- Standard: 申請支援
- Pro: 高度な申請支援・複数事業

競合調査と顧客ヒアリング後に決定する。

## 事業リスク

- 無料検索サイトとの差
- NPOの支払い能力
- AIコスト
- 公募情報取得の安定性
- AI誤判定
- 大手AI/助成金プラットフォームによる内製化
- 専門家サービスとの差別化

## 防御力

AIモデルそのものではなく、以下をサービス固有資産として蓄積する。

- 正規化された助成金DB
- NPOプロフィール
- 申請履歴
- 採択/不採択データ
- 情報源更新履歴
- マッチング評価
- 申請ワークフロー
