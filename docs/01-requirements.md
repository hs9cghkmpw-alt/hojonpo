# 要件定義

## 対象ユーザー

専任の資金調達担当者を持たない小規模〜中規模NPOを主対象とする。

想定課題:
- 公募情報を毎日探す時間がない
- 助成金制度に詳しくない
- 過去資料を再利用できていない
- 申請書作成に時間がかかる
- 締切管理を記憶に依存している

## MVP必須機能

### 団体
- 団体登録
- 法人格、所在地、活動地域、活動分野、対象者等の登録
- 団体資料アップロード
- 団体プロフィール編集

### 助成金
- 公募情報登録
- 出典URL
- 募集期間
- 締切
- 助成額
- 対象法人
- 対象地域
- 対象分野
- 募集要件
- 公式資料
- 取得日時・更新日時

### マッチング
- 明示条件の機械判定
- AIによる意味的な詳細判定
- 適合理由
- 不適合理由
- 不確実条件
- 根拠資料へのリンク

### 通知
- 新規マッチング
- 締切接近
- 募集要項更新
- 申請タスク期限

### 申請支援
- 応募案件管理
- 必要書類一覧
- 不足情報一覧
- 申請書ドラフト
- 予算ドラフト
- レビュー
- 人間承認

## MVPでやらない

- 自動提出
- 採択保証
- すべての自治体・財団の完全網羅
- 完全自律エージェントへの全面依存
- 複雑な大企業向け権限管理

まず「正確に拾う・正確に届ける・申請準備を楽にする」に集中する。
