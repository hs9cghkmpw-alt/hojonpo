# hojonpo プロダクト全体像

## 目的

hojonpo は、NPOの資金調達を「助成金検索」ではなく「継続的な資金調達業務」として支援するSaaSを目指す。

NPOが一度団体情報を登録すると、サービス側が継続的に助成金・補助金等の公募情報を収集し、団体との適合性を判定し、重要度の高い案件を通知する。応募意思が示された案件については、申請準備・資料整理・締切管理・申請書ドラフト作成まで支援する。

## コア価値

1. 団体ごとに使えそうな資金源を継続監視する
2. 新規情報を発見したら条件に合う団体へ速やかに届ける
3. 「なぜ自分たちに合うのか」を説明する
4. 応募したい案件について次に何をすべきかを提示する
5. 団体資料・過去申請を次回以降も再利用する

## 設計原則

### 自社システムが主体
情報監視、取得、正規化、保存、通知、締切管理はアプリケーション側が担う。

### AIは機能部品
OpenAI、Gemini、Claude等は分析・文章生成・対話・申請支援を担当する。サービス全体を特定AIの自走機能に依存させない。

### 一次情報をsource of truthにする
金額、締切、対象者、法人格、地域等の重要情報は公式募集要項・公式ページへ戻れるようにする。

### 人間が最終責任を持つ
申請書、予算、適格性判断、提出は人間確認を経て確定する。

## 完成形

NPO登録 → 団体プロファイル構築 → 資金源の継続監視 → 新規公募検出 → 条件フィルタ → AI詳細マッチング → 通知 → 応募意思 → 申請準備 → AI支援 → 人間確認 → 提出 → 結果・実績蓄積 → 次回マッチング改善
