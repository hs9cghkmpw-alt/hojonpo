# hojonpo

NPO向けの継続的な資金調達支援サービス。

## プロダクトコンセプト

**NPOの資金調達担当機能を、継続的なSaaSとして提供する。**

NPOが団体情報を登録すると、サービス側が助成金・補助金等の公募情報を継続監視し、団体ごとに適合する案件を分析して通知する。応募後は申請準備、資料整理、ドラフト作成、締切管理まで支援する。

重要な設計方針は、**サービス本体を特定AIの自走機能に依存させないこと**。情報収集・スケジュール・DB・通知・ワークフローは自社システムが制御し、AIは分析・文章生成・申請支援の部品として利用する。

## 全体フロー

NPO登録 → 団体プロファイル → 公募情報の継続監視 → 新規公募検出 → ルールフィルタ → AI詳細マッチング → 通知 → 応募意思 → 申請準備 → AI支援 → 人間確認 → 提出 → 結果・実績蓄積

## 現在の方針

最初から「全国すべての助成金」を扱うのではなく、少数の情報源と少数のNPOでMVPを作り、情報取得精度・マッチング精度・通知速度・申請支援の価値を検証する。

## 開発原則

1. 一次情報をsource of truthにする
2. AI判定と事実データを分離する
3. AI停止時もサービス基盤を利用可能にする
4. 同一情報の二重登録・二重通知を防ぐ
5. 重要操作は人間承認を必須にする
6. AIのコストと実行履歴を可視化する
7. 1万団体を想定しても全件AI処理しない
